# Lite Android Build

Цель: минимальный размер релизной сборки без отключения функций.

## APK для прямой установки

```bash
flutter clean
flutter pub get
flutter build apk --release --split-per-abi --tree-shake-icons
```

Не распространять universal APK, если нет необходимости поддерживать
одним файлом все ABI.

## Google Play / внутреннее распространение AAB

```bash
flutter build appbundle --release --tree-shake-icons
```

## Правила проекта

- не добавлять библиотеку, если функция уже надёжно реализуется
  Flutter/Dart или существующей зависимостью;
- не хранить изображения как BLOB в SQLite;
- не декодировать полноразмерное фото для миниатюры;
- большие списки читать порциями;
- тестовые данные не включать в backup;
- архивировать старые фото отдельно от текстовой истории.
